# Pinta con los Pintamigos

Web para colorear los 40 dibujos del libro *Los Pintamigos · Libro 1*.

Publicada en https://lospintamigos.github.io/colorear/ (destino del código QR de la página 93 del libro).
Sin anuncios, sin registros y sin datos de los niños: los dibujos pintados se guardan solo en el propio dispositivo.
